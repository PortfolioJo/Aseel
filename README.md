# Aseel Alzawahreh - Portfolio Website

موقع بورتفوليو احترافي لمطور Full-Stack متخصص في بناء لوحات تحكم وأدوات ذكية.

## المميزات

- ✅ تصميم عصري وجذاب
- ✅ متجاوب مع جميع الأجهزة
- ✅ دعم كامل للغة العربية والإنجليزية
- ✅ تأثيرات تفاعلية سلسة
- ✅ تحميل ديناميكي للبيانات من JSON
- ✅ سريع التحمل والأداء

## التقنيات المستخدمة

- HTML5
- CSS3 (Flexbox, Grid, CSS Variables)
- JavaScript (ES6+)
- Font Awesome Icons
- Google Fonts

## كيفية الاستخدام

1. قم بتنزيل جميع الملفات
2. ضع صورتك الشخصية في `assets/images/profile.jpg`
3. قم بتعديل ملف `data.json` وفقاً لبياناتك الشخصية
4. افتح `index.html` في المتصفح
